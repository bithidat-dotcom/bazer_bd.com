## ✨ Features

- **Modern iOS-Inspired UI:** Built with clean layouts, translucent components, and glassmorphism styling.
- **Smart Offline Fallback:** Automatically detects network status and gracefully switches to a built-in offline handler.
- **Interactive Mini-Game:** Keep users engaged with an embedded shopping-themed catch game right inside the offline fallback view.
- **Lightning Fast Performance:** Optimized for edge delivery and instant loading speeds.
